# Бот анонимных вопросов для Telegram — готовый бот для botdepo

Кто угодно пишет боту — вы получаете вопрос **без имени автора** и
отвечаете обычным «Ответить» в Telegram. Ответ уходит автору, а автор так и
остаётся анонимным. Подходит для канала, блога, школы, команды.

Настраивать на сервере ничего не нужно: только токен от @BotFather. Остальное — командами прямо в чате с ботом.

## Запустить за минуту

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram: `/newbot` → придумать имя → скопировать токен.
2. Зарегистрируйтесь на [botdepo.ru](https://botdepo.ru) → «Новый бот» → выберите «Анонимные вопросы» в готовых ботах
   (или вставьте ссылку на этот репозиторий в поле «Репозиторий»).
3. Вставьте токен и нажмите «Задеплоить». Через минуту бот работает.
4. Если запускаете через сервисного бота Botdepo, владелец закреплён заранее.
   При ручном запуске задайте `OWNER_ID` — ваш числовой Telegram ID.
   Без `OWNER_ID` остаётся прежний режим: первым напишите `/start`, до публикации ссылки.

## Как пользоваться

1. Напишите боту `/start` — появятся кнопки владельца: сборы вопросов, общая ссылка, приветствие, статистика и инструкция.
2. Поставьте ссылку на бота в описание канала, профиля или в сторис.
3. Вопрос пришёл — нажмите на него → «Ответить» и напишите ответ (можно фото или голосовое).

`/ban` — ответом на вопрос: больше не принимать сообщения от этого автора (кто это, вы так и не узнаете).
`/unban` — снять все блокировки. `/stats` — сколько вопросов пришло.
`/welcome текст` — своё приветствие для тех, кто откроет бота.
Приветствие также можно поменять кнопкой без команд. `/cancel` отменяет редактирование.
Между вопросами одного гостя действует пауза 10 секунд; заблокировать автора можно `/ban`.

Проверять бота удобно со второго аккаунта: сообщения владельца бот считает ответами, а не вопросами.

### Вопросы к конкретному посту

1. Нажмите **«Новый сбор»** и пришлите название темы, например «Поиск работы».
   Название — от 1 до 100 символов; `/cancel` отменяет создание.
2. Бот выдаст ссылку вида `https://t.me/ваш_бот?start=topic_…`.
   Поставьте её под постом, к которому хотите собрать вопросы.
3. Читатель открывает ссылку и запускает бота. Он увидит название темы
   и приглашение задать вопрос. Следующие сообщения относятся к этому сбору.
4. Вам приходит вопрос, привязанный через Reply к сообщению **«Сбор: Поиск работы»**.
   Это работает и с фото/голосовыми. Отвечайте именно на сообщение с вопросом,
   как обычно; ответ доставляется его автору.
5. **«Мои сборы»** показывает темы и количество доставленных вопросов.
   Нажмите тему, чтобы снова получить её ссылку. Старые сборы доступны
   через «Далее» и «Назад»; количество — вопросы, а не уникальные люди.

Можно вести несколько сборов одновременно. Каждый читатель переключается
между ними по ссылкам; выбранная тема сохраняется после перезапуска.
**«Задать общий вопрос»**, обычный `/start` или ссылка из кнопки
**«Общая ссылка»** (`?start=general`) сбрасывают тему. Неверная ссылка также
сбрасывает предыдущую тему и прямо предлагает задать общий вопрос.
Просто открытие чата по старой ссылке без `start` не обязательно присылает
боту команду — для сброса используйте кнопку или `/start`.

Открытие своей тематической ссылки владельцем показывает карточку сбора.
Приглашение для читателя проверяется со второго аккаунта.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `main.py` | бот: команды, кнопки, обработчики |
| `storage.py` | хранение данных в SQLite в `/data` |
| `requirements.txt` | библиотеки — по одной на строку |
| `AGENTS.md` | правила для ИИ-ассистентов |

## Поменять под себя

Нажмите **Use this template** вверху страницы — появится своя копия. В botdepo
создайте бота со ссылкой на неё (того, что запущен из этого репозитория,
удалите: один токен не может работать в двух ботах сразу). Меняйте код
прямо на GitHub и жмите «Передеплоить» в карточке бота.

Пишете с ИИ — ограничения платформы описаны в `AGENTS.md`, Cursor и Claude
Code читают его сами; в ChatGPT вставьте его в начало разговора.

## Где хранятся данные

В SQLite в папке `/data` — она переживает перезапуски и передеплои. Если
нужно сменить владельца, удалите бота в панели и создайте заново.
`OWNER_ID` не переопределяет уже записанного другого владельца: при конфликте
бот откажется запускаться. Тексты вопросов не сохраняются в SQLite.
Хранятся связь сообщения с ID автора, названия и случайные коды сборов,
выбранный читателем сбор и принадлежность доставленного вопроса к сбору.
Обновление SQLite добавляет таблицы и nullable-поле, сохраняя старые
маршруты ответов, настройки и блокировки.
Анонимность — перед получателем в интерфейсе бота, не перед Telegram.

## Проверки без настоящих сообщений

`python -m unittest -v` — захват владельца гостем, вопрос/ответ через mocked API,
ограничение повторов, блокировка и сохранение приветствия после переоткрытия БД.
Также проверяются сборы через настоящий aiogram dispatcher: создание и
проверка названия, тематические ссылки, вопросы с медиа и ответы, отдельный
контекст каждого читателя, переключение и сброс темы, страницы списка,
конкурентная отправка, права владельца, сбои доставки и обновление старой БД.
Это не замена проверке с двумя настоящими Telegram-аккаунтами.

## Запустить у себя на компьютере

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
BOT_TOKEN=ваш_токен python main.py   # Windows: set BOT_TOKEN=ваш_токен && python main.py
```

Не запускайте бота одновременно у себя и на botdepo с одним токеном —
Telegram отдаёт сообщения только одной копии.
